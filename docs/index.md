# Café Gestión
**Objetivo:** Sistema unificado de administración local para una cafetería y tostaduría.
**Módulos / Estructura:** Aplicación que incluye scripts de Python para migrar datos desde hojas de cálculo CSV hacia una base de datos centralizada SQLite (`cafe_gestion.db`).

- [Estandarización de Productores](estandarizacion-productores.md): Corrección y estandarización del catálogo de productores y sus referencias en los lotes.
- [Flujo y Estandarización de Fusión de Proformas](flujo-fusion-proformas.md): Estandarización de códigos (PR-YYYY-XXXX), estado inicial en Borrador y ocultamiento de proformas fusionadas de la lista principal.

### Arquitectura
- [Trazabilidad de Lotes y Blends](arquitectura/trazabilidad-lotes.md): Decisiones de diseño para la gestión inmutable de lotes verdes, tuestes parciales y creación de mezclas (blends).
