# Café Gestión - Sistema de Administración para Cafetería y Tostaduría

Este es el directorio de trabajo definitivo para tu aplicación web local de gestión, ubicado en `/home/rekels/Proyectos/cafe-gestion`.

## Instrucciones para la migración de datos:
1. Exporta tus hojas de cálculo actuales de Google Sheets como archivos `.csv`.
2. Guarda los archivos en esta carpeta (por ejemplo: `inventario.csv`, `tueste.csv`, `costos.csv`).
3. Notifícame cuando estén listos para que pueda analizar su estructura e iniciar la creación de la aplicación.
